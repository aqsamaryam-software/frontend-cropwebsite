# CropDoctor Static Demo

This is a static frontend preview created from the supplied Laravel project.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example: `cropdoctor-demo`).
2. Upload `index.html` to the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub to publish the website. The public URL will appear in the Pages section.

## Demo limitations
- This is a static frontend only. Laravel/PHP, database, login, registration, scan storage, and real AI diagnosis are not connected.
- The crop photo preview works in the browser. The sample diagnosis is illustrative only.
- Do not use sample scan results as agricultural advice.
